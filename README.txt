Яндекс Архив — сбор людей округи (расширение для Chrome)
=========================================================

УСТАНОВКА (один раз)
1. Распакуйте архив yandex-archive-extension.zip в любую постоянную папку
   (например, в «Документы»). Папку потом не удаляйте и не переносите.
2. В Chrome откройте chrome://extensions
3. Справа вверху включите «Режим разработчика».
4. Нажмите «Загрузить распакованное расширение» и выберите папку
   yandex-archive-extension (ту, где лежит manifest.json).
5. Для удобства закрепите значок расширения (иконка-пазл в панели Chrome).

РАБОТА
1. Войдите в Яндекс в этом же Chrome (откройте https://ya.ru/archive).
2. Нажмите на значок расширения — откроется страница «Яндекс Архив — сбор людей округи».
3. Выберите файл list_links.html со ссылками.
4. Нажмите «Выбрать, куда сохранить Excel, и начать» и укажите файл result.xlsx.
5. Расширение открывает рабочую вкладку, по очереди загружает страницы из диапазонов
   ваших ссылок и после каждой ссылки обновляет Excel-файл.
   Если Яндекс попросит капчу или вход — рабочая вкладка выйдет на передний план:
   решите капчу/войдите и нажмите «Продолжить» на странице расширения.
6. Страницу расширения не закрывайте, пока идёт работа. Кнопка «Остановить и сохранить»
   прерывает работу и сохраняет то, что уже собрано.

ЧТО ПОЛУЧАЕТСЯ
Excel-файл с листами «Люди», «Страницы», «Ссылки» — те же, что у скрипта на Python.
Диапазон страниц берётся ровно из ссылки (sheet_page_from … sheet_page_to).

ЕСЛИ ТЕКСТ НЕ РАСПОЗНАЁТСЯ
Расширение сохраняет в «Загрузки» файл first_page.html — HTML первой страницы.
Пришлите его, и селекторы блока с распознанным текстом можно будет подправить.
