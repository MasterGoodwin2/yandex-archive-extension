# Обработка списка ссылок графических образов, и обработка их в Gedcom

Расширение для Chrome. Тип данных: **«Скачать графические образы страниц из списка ссылок»** — только сканы страниц и таблица со ссылками.
Источник — файл `.ged` (генеалогический проект) или `.html` (список ссылок). Ссылки очищаются от `?center=`, дубликаты удаляются.
**Диапазоны не раскрываются**: берётся только страница, указанная в ссылке. Слипшиеся ссылки делятся на отдельные.

Выделено из расширения «Яндекс Архив — сбор людей округи» 3.0.1 (включает всё из 2.9.2); оформление, параметры и логика те же.
Сестринское расширение: «сбор людей округи» (исповедные ведомости и ревизские сказки).

## Параметры
- **Качество скана** (одно из трёх): Оригинальное 100%, Среднее 50%, Низкое 20%; размер в пикселях не меняется.
- **Папка результата** и **папка `Archive_Scans`** (по умолчанию `/Volumes/DATA/Archive_Scans`, путь в ссылках настраивается). Уже сохранённые сканы пропускаются.
- **Результат:** `result_links.csv` (UTF-8 с BOM, разделитель «;»; для `.ged` — первыми столбцами ID персоны INDI и имя), `result_links_all.csv`, `list_links_fixed.html`, журнал.
- **Запись в GEDCOM** (навык «Запись в GEDCOM», только для `.ged`): вариант **Источник** (SOUR + файл скана, у персоны ссылка с PAGE) или **Общий медиа-объект** (OBJE);
  запись **в копию** `<имя>_со_сканами.ged` или **в исходный файл** (рядом копия `<имя>_до_сканов.ged`). Существующие записи не дублируются: новая пишется другим вариантом,
  если оба вида уже есть — пропуск. Повторный запуск заменяет собственные записи (`@YA_S…@`, `@YA_M…@`).

## Установка
`chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка этого репозитория (где лежит `manifest.json`). Войдите в Яндекс в этом же Chrome (ya.ru/archive).

## Структура
`app.html`, `app.js`, `background.js`; `links-tools.js` (разбор ссылок, CSV), `gedcom-writer.js` (запись в GEDCOM), `page-scripts.js`, `excel-sheets.js`, `logic.js`;
`tests/` — `node tests/run_links.js`, `node tests/run_gedcom_writer.js`; сквозная: `xvfb-run -a python3 tests/e2e/run_e2e.py <links|links_html> <папка> --chrome <chrome>`.
