# сбор людей округи

Расширение для Chrome. Собирает людей округи из **исповедных ведомостей** и **ревизских сказок** Яндекс Архива по списку ссылок (`.html`),
сохраняет Excel и выполняет **итоговую обработку** внутри самого расширения — Терминал и Python не нужны.

Выделено из расширения «Яндекс Архив — сбор людей округи» 3.0.1 (включает всё из 2.9.2). Сестринское расширение:
«Обработка списка ссылок графических образов, и обработка их в Gedcom».

## Типы обработки
- **Исповедные ведомости.** Заголовки: село / деревня (в т.ч. «Того села»). Одна строка Excel = один человек: его часть текста Основного блока (как распознана), пол,
  номер (м№/ж№), возраст и год рождения (год ведомости − возраст). Двор — № из левого столбца. «Показанія дѣйства» не собираются. Лист «Блоки текста» — блоки целиком для проверки деления.
- **Ревизские сказки.** Заголовки: также починок, выселок, слобода, хутор и т. п. Одна строка Excel = один двор (семья). Данные берутся из готовой разметки страницы:
  список людей блока «Крестьяне/Крестьянки» как распознан, а рядом по строкам таблицы: лѣта по ревизии, когда выбыл, лѣта нынѣ. Лист «Строки» — то же построчно.

Вид Excel (исповедные / ревизские) выбирается переключателем независимо от типа обработки.

## Что умеет
- Сохранение оригиналов сканов страниц («Сохранить Скан», JPG 40%) в `Archive_Scans`, столбец «Локальная Ссылка на страницу», «Архив хранения документа».
- **Итоговая обработка** (общий скрипт yaarchive 3.3.0, Python в WebAssembly, папка `engine/`): единая таблица людей `Итог/Итог_люди.xlsx`, `Итог_древо.ged`,
  `Итог_люди.json`, `Отчёт.txt`; навык «Исправление ошибок» с окном решений; навык «Строки таблицы».

## Установка
`chrome://extensions` → «Режим разработчика» → «Загрузить распакованное расширение» → папка этого репозитория (где лежит `manifest.json`).

## Структура
- `app.html`, `app.js`, `background.js` — окно и работа расширения; `logic.js`, `layout.js`, `confession-rows.js`, `revision-rows.js`, `names-ru.js`, `excel-sheets.js`, `xlsx-writer.js`, `page-scripts.js`, `links-tools.js` — разбор.
- `engine/` — Pyodide и `engine.zip` (собранный движок); `engine-src/` — исходники движка, пересборка: `python engine-src/build_engine.py` (нужен `openpyxl`).
- `tests/` — проверки: `node tests/run_*.js`; сквозная в Chromium: `xvfb-run -a python3 tests/e2e/run_e2e.py <conf|rev|conf_as_rev> <папка> --chrome <chrome>`.
