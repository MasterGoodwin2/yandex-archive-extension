# yandex_archive_scraper

Python-скрипт: массовая обработка ссылок из `list_links.html` и сбор данных о людях «своей округи»
из исповедных ведомостей Яндекс Архива. Результат — Excel.

Расширение для Chrome на основе этого скрипта: [yandex-archive-extension](https://github.com/MasterGoodwin2/yandex-archive-extension).

## Установка
```
python3 -m pip install -r requirements.txt
```
Нужен Google Chrome (скрипт запускает его сам или подключается к Chrome с `--remote-debugging-port=9222`).

## Запуск
```
python3 yandex_archive_scraper.py
```
Скрипт спросит HTML со ссылками и место сохранения Excel; вход в Яндекс вы выполняете сами в окне браузера.

## Правила
- Год — из названия ссылки; диапазон — `sheet_page_from`…`sheet_page_to`; `ya.ru` и `yandex.ru` равнозначны.
- Проверка диапазона: ±3 страницы; если найдено меньше 4 из 6 населённых пунктов округи — ссылка пропускается.
- Ничего не менять, не достраивать, не удалять: текст записей как распознан, без разбора имён.
- Сопоставление по координатам блоков: № двора ↔ № мужчины/женщины ↔ запись ↔ возраст.
- Лист «Люди»: одна строка = один двор, все люди двора в одной ячейке; ссылка на страницу — только у двора.

Статус: сопоставление блоков проверено на тестовых раскладках, на реальных страницах — нет.
При первом запуске в `debug_yandex_archive/` сохраняются файлы для настройки.
